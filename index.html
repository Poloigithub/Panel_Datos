PD Panel de datos

Datos oficiales, a un clic

Panel de acceso a series estadísticas publicadas por organismos oficiales. Los datos se descargan automáticamente de sus APIs y se guardan en este repositorio, así que cada cifra es trazable hasta su fuente.

Cómo se actualiza

Una tarea programada consulta la API del INE, guarda las series en data/ y publica el panel. Si el INE no ha publicado nada nuevo, no se toca nada. El histórico de cambios de cada cifra queda en el propio historial de git.

Datos: INE. Elaboración propia.
